# GoldenRatio

## Nombre d'or (Golden Ratio)

Ce projet implémente le calcul du **nombre d'or** (φ) via la formule algébrique exacte :

```
φ = (1 + √5) / 2 ≈ 1.618033988749895
```

### Utilisation

```python
from src.math_utils import golden_ratio

phi = golden_ratio()
print(phi)  # 1.618033988749895
```
